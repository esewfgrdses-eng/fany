2. Módulo MySQL (Base de Datos)

2.1 Creación de Base de Datos y Tablas

Comandos SQL para inicializar el entorno de almacenamiento de datos:

-- 1. Crear la Base de Datos
CREATE DATABASE sistema_escolar;
USE sistema_escolar;

-- 2. Crear la Tabla de Alumnos
CREATE TABLE alumnos (
    id_alumno INT AUTO_INCREMENT PRIMARY KEY,
    nombre VARCHAR(50) NOT NULL,
    apellido VARCHAR(50) NOT NULL,
    email VARCHAR(100) UNIQUE,
    fecha_registro DATE DEFAULT CURRENT_DATE
);

2.2 Registro de Datos (INSERT)

Sintaxis para insertar información en las tablas:

-- Insertar registros individuales o múltiples
INSERT INTO alumnos (nombre, apellido, email) 
VALUES 
('Naomi', 'Martínez', 'naomi@example.com'),
('Leonardo', 'Mendoza', 'leonardo@example.com');

2.3 Consultas (SELECT)

Diferentes formas de consultar y filtrar datos guardados:

-- Consultar todos los campos de la tabla
SELECT * FROM alumnos;

-- Consulta con filtro condicional
SELECT nombre, email 
FROM alumnos 
WHERE id_alumno = 1;

-- Consulta ordenada por nombre
SELECT * FROM alumnos 
ORDER BY nombre ASC;
